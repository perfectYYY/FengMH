### 架构要点
- SIM 模式：`set_position(pos)` → `d->state.angle_rad = pos`（原行为不变）
- TWIN 模式：`set_position(pos)` → 仅记录 target；`inject_motor_angle()` → 写入实际值
- 数据流：MCU USB CDC → 串口读线程 → proto_frame_parser → 0x81 帧 → host_sim_inject_motor_angle()
- 线程安全：pthread_mutex_t 保护 motor state
