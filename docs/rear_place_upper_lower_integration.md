# 后放置上/下位机联调清单

本文档用于上位机 ROS 2 和 STM32 下位机联调独立后放置模式。以当前
`robot_serial_bridge` 和 `rear_place_planner` 的实际行为为准。

## 1. 职责边界

| 上位机负责 | STM32 负责 |
| --- | --- |
| 颜色识别、物资和 A/B 后槽匹配 | 按模式执行机械臂、泵和安全保护 |
| 相机坐标解算为机械臂基座坐标 | 机械臂运动学、轨迹、限位和碰撞保护 |
| 发送模式、目标和泵命令 | 持续发送真实末端位置和 `theta1_rad` |
| 任务成功后删除库存记录 | 目标到达、故障和模式切换时维护独立状态 |

STM32 不接收颜色、物资编码、库存文件或相机坐标。STM32 只接收已经在
机械臂基座坐标系中解算好的目标，单位是米。

## 2. 串口协议

物理链路为 STM32 USB CDC，`115200 8N1`，原始字节流。只能由
`robot_serial_bridge` 打开该设备。

所有帧格式：

```text
0x55 | 0xAA | func_id | payload_len | payload | checksum
```

`checksum` 是前面所有字节相加后取低 8 位。所有 `float32` 都是
IEEE-754 小端序。解析器必须能处理分包、粘包和坏帧后的重新同步。

| 方向 | 功能号 | 名称 | 载荷 |
| --- | ---: | --- | --- |
| 上位机 -> STM32 | `0x10` | 底盘命令 | `float32 vx, vy, wz`；后放置期间均为零，禁止底盘运动 |
| 上位机 -> STM32 | `0x11` | 机械臂目标 | `uint8 target_type, float32 x_m, y_m, z_m` |
| 上位机 -> STM32 | `0x14` | 泵命令 | `uint8 pump_on`，`0` 关、非零开 |
| 上位机 -> STM32 | `0x15` | 模式命令 | `uint8 mode` |
| STM32 -> 上位机 | `0x86` | 机械臂反馈 | `uint8 arm_state, float32 end_x_m, end_y_m, end_z_m, theta1_rad` |

## 3. 模式与门控

| mode | 名称 | STM32 行为 |
| ---: | --- | --- |
| `0` | `IDLE` | 停止新机械臂目标，关闭泵，清理后放置状态 |
| `1` | `NAV` | 不执行机械臂目标或泵命令 |
| `2` | `ARM` | 普通抓取任务；任务状态必须与后放置独立 |
| `3` | `ESTOP` | 急停或本机安全保持 |
| `4` | `ERROR` | 不执行新目标，关闭泵或进入安全保持 |
| `5` | `REAR_PLACE` | 独立后放置任务，允许 `0x11` 和 `0x14` |

实现要求：

1. `ARM=2` 与 `REAR_PLACE=5` 不得复用同一个轨迹、到达标志、泵保持或
   错误状态。
2. 收到不同模式时，立即停止旧轨迹、关闭泵、清理旧任务状态，再进入新模式。
3. 同一个模式帧会重复到达，必须幂等，不能反复重置正在执行的任务。
4. 当前模式不是 `ARM` 或 `REAR_PLACE` 时，忽略新的 `0x11`，并强制关闭泵。
5. 上位机离开 `ARM` 或 `REAR_PLACE` 前会先发送 `0x14 pump_on=0`，再发送
   新的 `0x15`。下位机也必须自行保证模式切换时泵关闭。

建议下位机逻辑：

```text
on_mode(new_mode):
    if new_mode != current_mode:
        stop_arm_trajectory()
        pump_off()
        clear_task_state(current_mode)
        current_mode = new_mode

on_arm_target(target):
    if current_mode not in {ARM, REAR_PLACE} or arm_state == ERROR:
        ignore_target()
    elif target is identical to active_target:
        keep_running_without_restart()
    else:
        execute_target(target)

on_pump(value):
    if current_mode in {ARM, REAR_PLACE} and arm_state != ERROR:
        set_pump(value)
    else:
        pump_off()
```

## 4. 机械臂目标与反馈

`0x11` 的载荷长度为 13 字节：

| 偏移 | 类型 | 字段 | 约束 |
| ---: | --- | --- | --- |
| 0 | `uint8` | `target_type` | `0=GRASP`，`1=PLACE` |
| 1 | `float32_le` | `x_m` | 机械臂基座 X，单位 m |
| 5 | `float32_le` | `y_m` | 机械臂基座 Y，单位 m |
| 9 | `float32_le` | `z_m` | 机械臂基座 Z，单位 m |

不要把坐标当作毫米，也不要对 `PLACE` 坐标再做相机变换。后放置 `PLACE`
阶段的 Z 固定为 `0.02 m`。

`0x86` 的载荷长度为 17 字节。反馈要求：

- 新目标后 1 秒内发送 `MOVING=1` 或有效的 `REACHED=2`。
- 持续发送反馈，间隔不得大于 0.5 秒，建议 20 Hz。
- `end_x_m/end_y_m/end_z_m` 必须是实际末端位置，不能直接回填目标值。
- `theta1_rad` 必须为当前第一关节角度，单位 rad。
- 到达后才发送 `REACHED=2`；同一目标的重复 `0x11` 不能让机械臂重新启动。
- 限位、逆解失败、碰撞或无法继续运动时，发送 `ERROR=3`，停止轨迹并关泵。

## 5. 后放置时序

上位机每次启动最多处理一件物资。后放置模型的颜色和物资映射在上位机完成：
`red=medicine=0`、`blue=ins=1`、`gray=tool=2`、`green=food=3`。

| 顺序 | 上位机动作 | STM32 必须行为 |
| ---: | --- | --- |
| 1 | 发送并维持 `0x15 mode=5` | 切换到独立后放置状态，关泵，持续反馈 |
| 2 | 本地等待 3 秒 | 不需要移动到上位机未指定的位置，保持可接收目标 |
| 3 | 发送 `0x11 GRASP` | 执行后槽抓取目标，反馈 `MOVING` 后再反馈真实 `REACHED` |
| 4 | 收到到达后发送 `0x14=1` | 开泵；重复开泵帧保持幂等 |
| 5 | 保持抓取约 1 秒，发送 `0x11 PLACE` | 执行视觉放置目标，不修改其 X/Y 和固定 Z=0.02 |
| 6 | 收到到达后保持约 1 秒，发送 `0x14=0` | 关泵；重复关泵帧保持幂等 |
| 7 | 等待约 2 秒，发送 `0x15 mode=0` | 清理后放置任务并进入 IDLE |

后槽抓取目标是固定的，STM32 不需要识别 A/B：

| 后槽 | 库存标识 | `GRASP` 目标 `(x_m, y_m, z_m)` |
| --- | --- | --- |
| 左后 | `A` | `(-0.2170, 0.2200, 0.3635)` |
| 右后 | `B` | `(-0.2170, -0.2200, 0.3635)` |

## 6. 重复帧、超时与故障

- 上位机模式帧默认约 5 Hz 重复；`0x15 mode=5` 重复时不能重新开始任务。
- 上位机在未收到 `MOVING` 或有效 `REACHED` 前可能重发同一个 `0x11`。
- 泵状态会在保持阶段重复发送；相同 `0x14` 只更新状态，不能产生泵抖动。
- 上位机 3 秒未收到反馈会关闭泵并发送 `IDLE=0`。
- STM32 发送 `ERROR=3` 后，上位机关闭泵并发送 `IDLE=0`；下位机收到 IDLE
  后清除本次故障任务状态，等待下一次模式启动。

## 7. 联调验收记录

双方各自保留同一次测试的日志，并按时间戳比对。一次成功任务的 STM32 接收
日志至少应出现：

```text
0x15 mode=5
0x11 target_type=0 (GRASP)
0x14 pump_on=1
0x11 target_type=1 (PLACE, z_m=0.02)
0x14 pump_on=0
0x15 mode=0
```

出现以下现象时优先检查对应项：

| 现象 | 优先检查 |
| --- | --- |
| 后放置模式下不执行目标 | STM32 是否把 `mode=5` 当作允许机械臂的模式 |
| 上位机一直等待到达 | 是否持续回传 `0x86`、字段是否为米、`REACHED` 是否为真实位置 |
| 每次重发目标都重新起步 | 是否按“相同目标幂等”处理 `0x11` |
| 抓取后立刻掉箱 | `mode=5` 是否允许 `0x14=1`，泵状态是否被模式逻辑错误关闭 |
| 模式切换后仍在运动或泵未关闭 | 模式边沿是否停止轨迹、清理任务并关泵 |
| 放置高度错误 | `PLACE` 帧 `z_m` 是否为 `0.02`，是否误用毫米或重复做相机变换 |
